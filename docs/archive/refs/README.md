# Hero Slide References

Эти файлы сохраняют смысл референсов из чата для новой сессии.

## Файлы

- `lying-person-full-width-reference.svg` — поза: человек лежит расслабленно во всю ширину слайда, текстовая зона слева свободна, ноут справа.
- `stickman-line-style-reference.svg` — стиль персонажа: простой черный line-art / meme stickman без реализма и лишних деталей.

## Важно

Оригинальные вложения из чата нельзя надежно извлечь как локальные файлы после отправки, поэтому здесь сохранены рабочие локальные рефы по смыслу:

- человек не справа отдельным портретом, а лежит горизонтально через весь первый слайд;
- персонаж простой, нарисованный черной линией;
- ноут/инфографика справа;
- на ноуте/в инфографике большая желтая папка и много курсоров-агентов.

Основной бриф: `docs/hero-slide-visual-brief.md`.
