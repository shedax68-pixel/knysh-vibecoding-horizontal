# Archive

Здесь лежат неактивные материалы проекта, которые не подключены к текущему лендингу.

- `prototypes/html/` — HTML-прототипы старых визуальных направлений.
- `prototypes/images/` — PNG-экспорты прототипов и вариантов первого экрана.
- `refs/` — SVG-референсы для генерации и стилизации персонажа.
- `assets/` — запасные ассеты, которые сейчас не используются на странице.

Активный сайт в корне использует `index.html`, `styles.css`, `Assets/alexander-knysh-avatar.jpeg` и `Assets/neurozeh-js-meme.png`.
